# Day 02 – Arrays

## Description

Day 02 focuses on strengthening the fundamentals of **Arrays in Java** through problem-solving and coding practice.

### Topics Covered

* Array traversal and iteration
* Finding maximum and minimum elements
* Searching elements in an array
* Calculating sum and average
* Reversing an array
* Basic array manipulation
* Solving common array-based coding problems

### Goal

Build a strong understanding of arrays and improve problem-solving skills by implementing solutions independently in Java.

### Language

**Java**

### Practice

This day contains multiple array-based problems with individual solutions to improve coding logic and consistency.
