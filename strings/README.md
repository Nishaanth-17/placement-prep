# String

This file contains solutions to string-related problems.

## Topics Covered

- String traversal
- Character frequency
- Palindromes
- Anagrams
- Substrings
- String manipulation
- Two pointer technique
- Sliding window

## Problems

| Problem | Approach | Time Complexity | Space Complexity |
|---------|----------|-----------------|------------------|
| Valid Anagram | Hash Map | O(n) | O(n) |
| Longest Substring Without Repeating Characters | Sliding Window | O(n) | O(n) |
| Valid Palindrome | Two Pointers | O(n) | O(1) |

## Complexity

The complexity depends on the individual problem and approach used.

## Language

Solutions are implemented in Java.
